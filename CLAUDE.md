## Обязательные ограничения владельца

- Не изменять установленные toolchain в WSL UbuntuCafeF. Не выполнять apt/pacman,
  make install, обновление SDK или запись в /opt/wiiu-rnd и каталоги SDK.
  Сборка зависимостей внутри vendor/build проекта разрешена при работе над кодом.
- Native аппаратная активация требует отдельного явного согласования конкретного
  кандидата и процедуры восстановления. Старое разрешение на allocation diagnostic
  не является разрешением на новый драйвер, reboot или произвольные записи IOS.
- На момент передачи цель Codex на паузе. Запрос владельца сейчас: подготовка
  документации и промпта для изучения. Сначала изучи, проверь выводы по файлам и
  представь результат. Код/консоль не менять в рамках первоначального изучения.
  Далее следуй непосредственным новым поручениям владельца.
- Не отключать Wi-Fi, не менять DHCP, сертификаты или настройки роутера в рамках
  подготовки. Оптимизация DHCP и одновременный Wi-Fi/Ethernet вне текущей задачи.
- Не запускать двух USB owners одновременно: PPC .wms и native IOS-NET.
- Не отправлять команды в существующую TCP-очередь и не заливать файлы без текущего
  подтверждения состояния консоли и соответствующего разрешения. См. CONSOLE.md.
- Не публиковать evidence/, OTP, SEEPROM, ключи, fw.img, ios.elf, дампы или полные
  журналы консоли. Хеши/адреса в документации не дают разрешения менять память.
- Согласовать отдельные наборы файлов для параллельной работы Codex/Claude. Корень
  проекта сейчас не является Git checkout; нельзя полагаться на git diff/reset.
- Не называть локальные тесты аппаратным успехом. Явно различать source, compiled,
  host-tested, ARM-emulated и console-tested.

Актуальный native loader пока не завершён. Существующий PPC-путь работал на консоли;
полный native RTL-драйвер, USB handoff, штатный DHCP и работа без Wi-Fi не доказаны.
